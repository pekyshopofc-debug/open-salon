# Plano: Traduzir Open Salon para Português do Brasil

## Escopo

Traduzir todas as strings visíveis ao usuário no frontend de inglês para pt-BR. A tradução é **direta e inline** (sem sistema de i18n) — cada string em inglês é substituída pela equivalente em português no mesmo arquivo.

**Não serão traduzidos:** nomes técnicos (variáveis, classes CSS, rotas de URL, nomes de colunas do banco de dados, nomes de dependências).
